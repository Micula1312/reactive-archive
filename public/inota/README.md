# INOTA media

Final performance target:

- master canvas: `3600 x 2400`
- duration: `08:00`
- ceiling: `x 0–3600 / y 0–1200`
- front screen: `x 840–2760 / y 1200–2400` (`1920 x 1200`)
- lower left/right areas remain black

## Final delivery

Use After Effects for the final `3600 x 2400 / 08:00` assembly, render a high-quality ProRes master with embedded audio, then convert the verified master to DXV3 in Resolume Alley. HandBrake is useful only for preparing browser-friendly source clips, not for the festival delivery master.
